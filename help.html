使用說明

    網頁版（用瀏覽器直接使用）

    這個 app 也有網頁版，不需要安裝，用瀏覽器打開網址就能用。功能和桌面版幾乎一樣，差別在檔案和輸出：

    項目網頁版
    你的文件放在哪裡只存在你的電腦，不會上傳到任何伺服器。內建經文（和合本、BSB、SBLGNT）是網頁的一部分，不需要另外連網取得。
    存檔／開啟Chrome、Edge、Opera：可以選一個 .verse 檔案，之後「存檔」直接存回同一個檔案（也有「另存新檔」）。Safari、Firefox：不能直接存回檔案，「存檔」會下載一個新的 .verse（每次都是新檔），「開啟」要自己去下載資料夾選檔。建議用 Chrome 或 Edge。
    匯出 PDF／列印會開啟瀏覽器的列印視窗：目的地選「另存為 PDF」，邊界選「無」，縮放 100%，並取消勾選「頁首和頁尾」。紙張是 A4。
    自動存檔與復原有未存的變更時，每隔幾秒（可以在偏好設定改）把內容暫存在這個瀏覽器裡；如果分頁當掉或不小心關掉，下次打開會問你要不要恢復。關閉或重新整理分頁前，有未存的變更會跳出瀏覽器的確認。
    備份版本沒有（那是桌面版的功能）。請自己定期存檔，或用「另存新檔」留幾個版本。
    偏好設定、全域關係表存在這個瀏覽器裡（localStorage）。換瀏覽器、換電腦、或清除網站資料就會不見，需要重設。
    清除瀏覽器的網站資料、用無痕視窗，會讓暫存的復原檔、偏好設定一起消失。重要的分析請記得存成 .verse 檔案，並放在你自己的備份裡。
    網頁版不含範例文件。想看操作範例，用「新增…→從聖經帶入經文」帶入一段經文就可以開始。

    安裝與開啟 app

    1. 在專案資料夾執行 npm run package，會在 release/經文結構分析-darwin-arm64/ 產生 經文結構分析.app。
    2. 把它拖進「應用程式」資料夾，之後雙擊就能開啟，不需要終端機或開發伺服器。
    第一次開啟如果被擋下（例如把 app 用 AirDrop、雲端硬碟或壓縮檔傳到別台 Mac 之後）：這個 app 沒有 Apple 開發者簽章，只有臨時簽章，所以 macOS 會提示「無法驗證開發者」。請在 app 上按右鍵 → 打開，再按一次「打開」，之後就不會再問。在建立它的那台 Mac 上直接開通常不會被擋。
    • 打包好的 app 和開發模式（npm run dev、npm run electron）各用各的使用者資料夾：偏好設定、全域關係表、備份、復原檔都不共用。你的 .verse 文件檔案本身不受影響，可以用「開啟」在任何一邊打開。
    • app 約 300MB（內含完整的 Electron 執行環境）。
    • app 圖示是專案裡的 assets/icon.icns（括號樹的圖案）。想換成自己的圖，改 scripts/make_icon.py 後執行 npm run icon，再重新 npm run package。

    快速上手

    這個 app 用來做經文的「括號樹」結構分析：把經文一行一行排好，用括號把有關係的行包起來，再標上它們的邏輯關係（因果、目的、解釋…），最後匯出成 A4 的 PDF。

    1. 打字或貼上經文。在頁面上直接打字（可以用注音等輸入法），或貼上一段文字。貼上多行時，每一行都會成為獨立的一行。
    2. 斷行。在想斷開的地方按 Enter，一行變兩行。要把兩行接回去，在下一行的行首按 Backspace。
    3. 調整縮排。按 Tab 縮排一階，⇧ Tab 退回一階（分析欄裡）。縮排只是文字的位置，不影響括號。
    4. 建立括號。點左邊的行號選取相鄰的幾行，按工具列的「建立括號」或 ⌘G。
    5. 指定關係。點括號的垂直線，右邊會出現面板，點關係的名稱（例如「因果」），設好主句，按「完成」。
    6. 存檔。按 ⌘S。
    7. 匯出。按「匯出 PDF」，如果還有沒做完的地方，會先列給你看。
    做錯了隨時按 ⌘Z 復原，⇧⌘Z 重做。每一個操作（建立括號、移動、貼上、改關係…）都是一個復原步驟。

    基本概念

    名詞意思
    行頁面上的一行文字。每一行可以有自己的縮排、對照欄文字。
    括號把 2 個以上相鄰的項目框在一起。括號左邊那條直角的線就是它。括號裡面可以再有括號。
    項目「行」和「括號」的統稱。移動、選取、建立括號都是對項目做的。
    關係括號裡各項目之間的邏輯關係，例如因果、目的、解釋。一個括號可以同時有好幾個關係（顯示成「進/*」這樣）。
    主句有主次之分的關係裡，被強調的那一個項目。它的標記用粗體；如果主句沒有標記文字，就顯示「*」。
    分析欄括號樹和縮排所在的那一欄，也就是你主要在打字、分析的那一欄。
    對照欄放在分析欄右邊的欄，例如譯文。最多兩個。
    閱讀順序由上到下的行順序。括號一定涵蓋「連續」的幾行，所以順序就是經文順序。

    畫面上的提示符號（列印和 PDF 不會出現）

    ? 黃色問號這個括號還沒指定關係，或某個標記被設成「待判定」。
    ! 紅色驚嘆號這個關係需要主句，但目前沒有任何項目被設成主句（缺主句）。
    ● 藍色小點這個標記是你自己改過的文字，之後切換主次時它不會自動更新。
    灰色小數字隱藏的經節錨點，用來保存經節歸屬，不列印（見「經節」）。
    紅框整節對照的譯文區塊太高放不進一頁。
    頁面之間的虛線A4 的換頁處。

    輸入與編輯行

    想做什麼怎麼做
    斷行游標放在想斷開的地方，按 Enter。游標前的字留在上一行，游標後的字到新的一行（連空白都原封不動）。
    合併上一行游標在行首時按 Backspace。兩行的文字直接接起來，不會多出任何字元。
    合併下一行游標在行尾時按 Delete（Mac 的 fn Delete）。
    縮排Tab 縮排一階、⇧ Tab 退一階，範圍 0 到 12 階。每階的寬度可以在「版面設定」改。
    強制換頁⌘ Enter：切換「這一行之前強制換頁」。
    上下行之間移動游標在行首按 ↑、在行尾按 ↓，會跳到上一行或下一行。
    貼上多行貼上的每一行都成為獨立的一行。如果游標所在的括號已經有關係，會自動多建立一個「未指定關係」的小括號，把貼出來的行包在一起。
    刪除行先點左邊的行號選取，再按 Delete 或工具列的「刪除行」。如果那些行的對照欄有內容，會先問你要一併刪除還是併入上一行。
    斷行時括號怎麼辦？如果這一行不在括號裡，或所在的括號還是「未指定關係」，新的一行就直接成為它的兄弟。如果所在的括號已經有關係，app 會建立一個「未指定關係」的小括號，把拆開的兩行包在裡面，原本那一行在大括號裡的標記（例如「因」）會移到小括號上，所以意思不會被縮小。

    用中文輸入法（注音）

    • 組字的時候按 Enter、Tab、Backspace 都是交給輸入法處理，不會拆行、縮排或合併。
    • 一次組字（從開始打到選字完成）是一個復原步驟。連續打字也會合併成一個步驟，停頓超過 1 秒、移動游標或做了別的操作才會分開。
    • 組字中按 ⌘Z 不會作用，等選字完成再復原。
    • 組字中點別的格子，目前組字的內容會先確定，再切換過去。

    選取行與括號

    要建立括號、移動、刪除，都要先「選取項目」。選取不是在文字裡拖曳（那是選文字，用來設粗體、底線），而是點下面這些地方：

    想選什麼怎麼做
    一行點那一行最左邊的灰色行號。那一行會出現淡藍色底。
    連續幾行點第一個行號，按住 ⇧ 再點最後一個行號。
    一個括號點它的垂直線（線會變藍），右邊會出現關係面板。
    加選／取消加選按住 ⌘ 再點行號，或點括號的垂直線。可以行和括號混著選。
    取消選取按 Esc，或按關係面板的「完成」。
    游標在某一行的文字裡、而沒有另外選取時，括號相關的快捷鍵（⌥↑、⌘[ 等）會作用在「游標所在的那一行」。

    括號

    建立括號

    選取 2 個以上相鄰、而且在同一個層級的項目（都在最上層，或都在同一個括號裡），按「建立括號」或 ⌘G。新括號依原順序包住它們。

    • 不能把父括號的全部子項都包起來（那等於什麼都沒變）。
    • 條件不符時，畫面最底下的狀態列會說明原因，例如「選取的項目必須相鄰」「選取的項目必須在同一個括號下」。
    • 新括號是「未指定關係」（黃色 ?）。被包進去的項目原本在父括號裡的標記會被拿掉（有標記時狀態列會告訴你拿掉了哪些），新括號在父括號裡的標記是「待判定」。

    在已經有的括號上再建一個括號

    括號 ＋ 一行：1、2 已經是一個括號，要把第 3 行一起包起來
    1. 點「1、2 那個括號」的垂直線（線變藍）。
    2. 按住 ⌘，再點第 3 行的行號。
    3. 按「建立括號」或 ⌘G。

    為什麼不能直接選行號 1、2、3？因為 1、2 在括號裡面，3 在外面，不在同一個層級。要把「1、2 的括號」當成一個整體項目來選。

    括號 ＋ 括號：1&2 一組、3&4 一組，要把兩組包在一起
    1. 點第一個括號的垂直線。
    2. 按住 ⌘，點第二個括號的垂直線。兩個括號的線都變藍。
    3. 按「建立括號」或 ⌘G。

    解除括號

    點括號的垂直線，按「解除括號」或 ⇧⌘G。括號裡的項目放回原位。如果這個括號在父括號裡有標記（例如「因」），會跳出視窗讓你選：標記要交給哪一個子項（其他子項變成待判定），或全部標成待判定。app 不會預先幫你選，因為那會默默決定分析的意思。

    移動

    想做什麼怎麼做
    上移、下移⌥↑、⌥↓：和同一個括號裡相鄰的兄弟交換位置，不會移出括號。標記跟著項目走。
    併入下方相鄰的括號⌘]（併入上方的：⇧⌘]）：項目成為相鄰括號的第一個（或最後一個）子項。
    移出括號⌘[：括號的第一個或最後一個子項，移到括號的前面或後面。
    拖曳見下面「拖曳移動」。

    自動整理

    每個會拿掉項目的操作做完後，app 會自動整理括號：括號被搬空就刪掉；只剩一個子項就解除，剩下的子項接手括號的位置，並繼承括號在父括號裡的標記。

    指定關係與標記

    點括號的垂直線，右邊會出現「括號關係」面板。每個按鈕按下去就已經生效，每個都是一個復原步驟，所以沒有「確定／取消」。設定完按面板上的「完成」關閉（或按 Esc）。

    項目說明
    加入關係點關係的名稱就加入。上面的輸入框可以打字篩選。需要主句的關係，預設最後一個子項是主句。一個括號可以加好幾個關係。
    換成別的關係已套用的關係旁邊的下拉選單。主句的指定盡量保留；新關係沒有主句時，主句指定會清除。你自己改過的標記文字保留。
    排序、移除↑ ↓ 改變多個關係顯示的先後（例如「進/*」變成「*/進」）；「移除」只移除這一個關係。移除最後一個關係，括號變回「未指定關係」。
    設為主句每一個分支旁邊的「主」圓點。三個以上子項時用它指定主句。
    交換主次只有兩個子項時出現，把主句和次要句對調。
    改標記文字在分支旁的輸入框改字，按 Enter 或點別處才會生效。改過的標記會有藍色小點。「↺」恢復成依關係表自動產生的文字。
    待判定 ?標記旁的「?」把這個標記標成「還沒決定」，之後再回來判斷。

    標記怎麼顯示

    • 有主次的關係：次要句和主句各有標記，主句用粗體；主句沒有標記文字時顯示「*」。
    • 沒有主句的關係（以及、或者、無關係，相比預設也是）：所有分支同等，標記整個括號只印一次，放在垂直線旁邊的中間。
    • 切換主次時，主句的粗體、「*」、缺主句提示會自動更新；但你自己改過的標記文字不會變（藍色小點提醒你）。
    「無關係」和「未指定關係」不一樣：「無關係」是你判斷這些子句之間沒有邏輯關係，會印出「--」；「未指定關係」是還沒分析完的括號（匯出前會提醒）。

    經節

    經節號不是普通的上標文字，而是有意義的「經節標記」。app 靠它記住每一段文字屬於哪一節，所以你怎麼拆行、合併、移動，它的歸屬都不會變。

    自動辨識（貼上時）

    • 只在貼上時進行。辨識的位置有三種：行首的數字（14 Καὶ…）、數字緊接文字（16For…、16神…）、章:節（3:16）。
    • 數字必須形成連續遞增的節號（14、15、16…）才會採用，至少兩個。其他數字（例如「40 晝夜」）保留成普通文字。
    • 沒寫章的，用工具列第二列的「起始章」；節號從大跳回 1 時，章自動加 1。
    • 貼上後，狀態列會顯示「辨識出 N 個經節」，旁邊有「取消經節辨識」按鈕，按下去只取消辨識、貼上的文字保留。這個按鈕只在貼上之後立刻出現。

    手動

    • 標為經節：在文字裡選取一個數字（例如 16），按工具列第二列的「標為經節」。章會取前一個經節的章。
    • 修改或移除：點一下頁面上的上標節號，會跳出視窗，可以改章、節、顯示或隱藏，或「改成一般文字」「刪除標記」。

    灰色的小數字是什麼？

    它是隱藏的經節錨點。你把某一行移到別處、或刪掉某一行之後，app 會在受影響的行首補上一個隱藏標記，記錄「這一行原本屬於第 16 節」，這樣歸屬才不會變。它只在螢幕上顯示成淡灰色，不會列印。app 會自動把不必要的錨點拿掉。

    文字標記

    工具列第二列：B 粗體、I 斜體、U 底線、x² 上標、四種螢光底色、四種文字顏色、「清除標記」。快捷鍵 ⌘B ⌘I ⌘U。

    • 先在文字裡選取要標記的字，再按按鈕。沒有選取時，按了之後打的字會帶這個標記。
    • 每一格是獨立的編輯器，所以不能跨行選取文字。要處理好幾行，請用左邊的行號選整行。
    • 每次標記是一個獨立的復原步驟。

    對照欄（譯文、另一種語言）

    新增

    工具列「版面設定…」→「對照欄」→「新增對照欄」。可以選語言（希臘文、英文、繁體中文）、模式、寬度、是否顯示，最多兩個。

    模式適合什麼情況
    逐行每一行分析欄文字旁邊有一格。適合一行對一行。
    整節一節的譯文放成一個區塊，往下跨越這一節涵蓋的所有行（一行含好幾節時，幾節的譯文依序疊在同一個區塊）。內容依經節存放，所以怎麼拆行、合併都不影響。
    切換模式不會刪除另一種模式的內容，兩種內容都保留。

    在格子裡打字

    • Enter：移到下一行的同一欄（不會斷行）。
    • Tab／⇧ Tab：移到下一格／上一格。
    • 整節欄：Enter、Tab 在各節之間移動。

    貼上到對照欄

    在對照欄的格子裡按 ⌘V，一律先顯示預覽視窗，不會直接覆蓋：

    • 逐格貼上：貼上的多行文字從你點的那一格開始，一行一格往下填。空白行會跳過那一格。
    • 依經節對齊：依貼上文字裡的經節號切開，每一節放到分析欄中「包含這一節」的第一行（整節欄則直接放進那一節）。需要分析欄有經節標記。
    • 預覽會標出：已經有內容的格子（可選覆蓋、接在後面、略過）、找不到對應行的經節、超出最後一行的文字（兩者可選併入最後一行，或取消整個貼上）。
    一行對一行時，貼上文字的換行要和分析欄的行數對得上。如果兩邊拆行的方式不一樣（例如中文一節拆三行，希臘文一節一行），可以貼上後直接在格子裡修改。

    帶入經文（和合本／BSB／SBLGNT）

    不用自己打字或貼上經文：選好書卷和章節範圍，再決定哪個語言放在分析欄、哪些放在對照欄，app 會自動建立一份新文件。

    1. 工具列的「新增…」選單 → 「＋ 從聖經帶入經文…」。
    2. 選書卷，再填起點與終點的章、節。畫面會顯示共幾節。
    3. 選語言配置：
      • 分析欄（一個）：中文（和合本）、英文（BSB）或希臘文（SBLGNT）。括號樹和縮排會畫在這一欄。
      • 對照欄（0 到 2 個）：其他語言各放一個對照欄。分析欄選的語言不能再放進對照欄。
    4. 要用「神」字的話勾選「和合本改用『神』字」（把「上帝」換成「神」）。
    5. 預覽前三節確認後，按「建立新文件」。有未存的變更時，會先問你儲存、不儲存或取消。

    常見的配置

    想做什麼怎麼選
    以中文為主分析，旁邊對照英文分析欄＝中文；對照欄＝英文
    以希臘文為主分析（像 NA28 的傳統做法），旁邊對照中英文分析欄＝希臘文；對照欄＝中文、英文（兩個都勾）
    只要原文，不要對照分析欄＝希臘文；對照欄都不勾

    產生出來的文件

    • 分析欄的文字是你選的語言，每一節一行，行首有經節標記。標題自動寫成例如「約翰福音三 14 至 21（SBLGNT、和合本、BSB）」。
    • 每個對照欄用「整節」模式：每一節的譯文放成一個區塊，之後你把某一節拆成好幾行，對照欄會自動跨越這一節涵蓋的所有行。
    • 有對照欄時，頁面預設橫向（放得下）；一個對照欄寬 30%，兩個各 22%。起始章是範圍的第一章。
    • 用到 SBLGNT 時，文件最後一頁的下邊界會印出來源標示（見下面的授權）。
    • 接著就照平常的方式分析：斷行、縮排、建立括號、指定關係。

    內建的版本與授權

    版本授權
    和合本（Chinese Union Version，1919，繁體）公有領域。在台灣、中國大陸和大多數地區沒有版權；香港聖經公會曾主張它在香港與澳門的權利，使用範圍含港澳時請自行確認。這份資料帶有「」『』等新式標點、用字是「上帝」版。「和合本修訂版」等修訂版仍有版權，沒有內建。
    Berean Standard Bible（BSB）2023 年 4 月 30 日起，翻譯團隊把它捐贈為公有領域（CC0）。
    SBL Greek New Testament（SBLGNT，只有新約）CC BY 4.0（不是公有領域）：可以自由使用，但必須標示來源。app 會自動把「SBL Greek New Testament © 2010 Society of Biblical Literature and Logos Bible Software, CC BY 4.0」印在最後一頁頁尾，請不要刪掉。
    NA28、UBS5 等 Nestle-Aland／UBS 版本有版權，沒有內建。SBLGNT 是現代批判本，和 NA28 在絕大多數地方用字一致（約翰福音 3:14–21 實測只有兩處不同：3:16 NA28 的 [ὁ θεὸς] 和 3:17 的省音拼寫）；如果你的分析一定要建立在 NA28 上，請自己貼上。資料來源與完整授權聲明在專案的 src/data/bible/SOURCES.md。經文是內建在 app 裡的，不需要網路。

    要注意的地方

    • 希臘文只有新約。選舊約的書卷時，希臘文選項會停用。
    • 各版本的節數不同：分析欄的版本決定有哪些節。其他版本若在範圍內有章節數不同（例如約翰福音 7 章：和合本 52 節，BSB 和 SBLGNT 53 節；使徒行傳 19、羅馬書 16、哥林多後書 13 等），預覽會用 ⚠ 提醒你那個版本可能和分析欄錯位。
    • 某個版本沒有的經節：那一節的欄位留空（分析欄只會有節號），帶入後狀態列會提醒。
    • 和合本有「」『』等新式標點；SBLGNT 保留文本本身的 [ ]；都沒有收錄經文裡的小標題。
    • 一次最多帶入 400 節。更長的段落，請分幾次帶入。
    • 之後想把分析欄和對照欄對調，可以用「交換分析欄與對照欄」（見後面的章節）。

    把內建經文加到既有文件的對照欄

    你已經有一份文件（分析欄是你自己貼上或打好的，例如 NA28 希臘文），想在旁邊加上和合本、BSB 或 SBLGNT 對照：工具列「加入經文對照…」。只會動對照欄，分析欄一個字都不會改。

    1. 選書卷（用過「帶入經文」建立的文件已經記住了，其他文件要自己選）。
    2. 選版本：中文（和合本）、英文（BSB）、希臘文（SBLGNT，只有新約）。
    3. 選加到哪裡：新的對照欄，或某個既有的對照欄。
    4. 如果那一欄的某幾節已經有內容，選「保留原本的（略過）」「覆蓋」或「接在後面」。
    5. 預覽確認後按「加入對照欄」。這是一個復原步驟。

    它怎麼對齊

    • 依文件裡已經有的經節標記，每一節放一段，放進對照欄的「整節」模式。所以分析欄怎麼拆行、合併，對照欄都會自動跨越那一節涵蓋的所有行。
    • 文件裡沒有經節標記就沒辦法對齊，會告訴你先用「標為經節」標好，或貼上帶有節號的經文（貼上時會自動辨識）。
    • 預覽會顯示文件裡的經節範圍和前三節。如果文件裡有某一節是那個版本沒有的（例如和合本沒有約 7:53），會列出來，那一節的欄位留空。

    加到既有的對照欄時

    • 如果那個欄原本是逐行模式，會改成整節模式；原本逐行的內容仍然保留，之後可以在版面設定切回去。
    • 欄的語言會改成你選的版本的語言（字型也跟著換）。
    • 對照欄最多 2 個。已經有 2 個時，只能選既有的欄。新欄的寬度預設 25%，其他欄占掉太多時會自動縮小，放不下就請你先縮小或關閉其他欄。

    授權標示

    加入 SBLGNT（CC BY 4.0）時，文件最後一頁的下邊界會自動補上來源標示，已經有就不會重複。授權細節見上一章「帶入經文」。

    交換分析欄與對照欄

    情境：你先用中文打好、分析好括號，後來把希臘文貼進對照欄，現在想「以希臘文為分析欄」，括號樹和標記都留著，只是樹狀圖旁邊的文字從中文換成希臘文。

    1. 先在「版面設定…」確認有一個逐行的對照欄，裡面已經有內容，並按「套用」。
    2. 再開「版面設定…」，在那個對照欄旁按「與分析欄交換…」。（有尚未套用的修改時，按鈕會停用。）
    3. 確認視窗會說明後果，按「交換」。可以用 ⌘Z 一次回到交換前。

    交換時發生的事

    • 每一行的文字（含粗體等標記）和欄語言對調。括號、關係標記、縮排、分頁點全部不變。
    • 經節標記只能放在分析欄，所以每一行的標記會依原順序集中到新分析欄文字的行首。沒有行中標記時，每一行的經節歸屬完全不變。
    • 如果有行中間的經節標記（一行含好幾節），標記移到行首後，那一行全部的新文字都歸給最後一個標記的經節。確認視窗會用紅字告訴你有幾行，交換後請檢查，必要時把那一行拆開。
    • 對照欄空白的行，交換後新分析欄那一行是空行（括號結構照留）。
    • 交換後兩欄各自用自己的語言的字型。
    只有「逐行」且「已經有內容」的對照欄能交換。整節對照欄不行。

    拖曳移動

    • 拖行：按住左側的行號往上或往下拖。已經選了好幾行時，拖其中一個行號就是一起移動。
    • 拖括號：按住括號的垂直線拖。
    • 拖的時候，指標停在某一行的上緣或下緣，會出現藍色落點線和「移動 N 項」。Esc 取消。
    • 選哪一層：同一個位置可能有好幾層可放（放在那一行旁邊，或放在包著它的括號旁邊，只有括號的第一個或最後一個子項才能選外層）。用指標的水平位置挑：越靠近縱線是越外層，越靠右就是放進括號裡。
    • 放在同一個括號裡重新排序時，標記跟著走；搬到別的括號，原本的標記捨棄（會提示），新位置的標記是待判定。
    • 移動後每一段文字所屬的經節不變（會自動補隱藏錨點）。

    版面設定與頁面

    工具列「版面設定…」，按「套用」後生效（一個復原步驟）。

    項目說明
    頁面方向、邊界A4 直向或橫向，四邊邊界（mm）。工具列的「直向／橫向」按鈕可以快速切換。
    分析欄語言希臘文、英文、繁體中文。決定這一欄用的字型。
    字級、每階縮排字級（pt）與每一階縮排的寬度（mm）。
    樹狀區左邊留白括號樹左邊留多少空白（mm）。
    版面縮放影響列印出來的大小，存在文件裡。放大表示同一頁放得下較少內容。
    檢視縮放工具列右邊的「檢視縮放」，只影響螢幕上看起來的大小（像放大鏡），不影響文件和列印。
    標記分隔符、主句加 *多個關係在同一個分支上用什麼連接（預設「/」）；主句標記是否一律加 *。

    版面過窄

    分析欄扣掉最深的縮排後少於 40mm 時，頁面上方會出現黃色提示列。app 不會自動偷偷縮小，而是請你選一個：改成橫向、版面縮放 −10%、字級 −1pt、每階縮排 −1mm，或關閉某個對照欄。

    分頁

    • 內容超過一頁會自動分頁；⌘ Enter 可以在某一行之前強制換頁。
    • 一般的行不會被切到兩頁，放不下就整行移到下一頁。
    • 一列比一頁還高（例如對照欄貼了很長的譯文）會自動跨頁切開，只在整行的邊界切。跨頁的列在畫面上是唯讀顯示，點一下會開編輯視窗編輯整格，按 Esc 或「完成」關閉。
    • 跨頁的括號，垂直線在每一頁都會接起來；分支標記畫在分支所在的那一頁。
    • 整節對照的區塊涵蓋的行要在同一頁。區塊比一頁還高，或被手動分頁點切開，就無法輸出（要縮短譯文、改橫向或拿掉中間的分頁點）。

    匯出前檢查、PDF 與列印

    按「匯出 PDF」或「列印」（⌘P）。如果有沒做完的地方，會先顯示清單，點清單裡的任一項會跳到那個位置。

    項目會不會擋下輸出
    整節對照區塊太高會，必須修正
    字型還沒載入完成會，等一下再試
    未指定關係的括號、待判定的標記、缺主句的關係、版面過窄不會，可以按「仍要輸出」
    • PDF 是向量格式，文字可以搜尋，字型內嵌。紙張 A4。
    • 畫面上的 ?、!、藍點、灰色錨點、行號、選取底色都不會印出來。
    • 這些提示在畫面上都看得到，所以匯出前的清單是在提醒你「輸出的內容裡還有沒完成的分析」。

    檔案、存檔與備份

    一個檔案（副檔名 .verse）對應一段經文。

    操作說明
    新增工具列的「新增…」選單：空白新文件、範例。選了會用它取代畫面上的文件（有未存的變更會先問你儲存、不儲存或取消）。
    存檔／另存新檔⌘S。存檔前會先驗證，驗證失敗表示 app 有錯，不會覆蓋原檔。
    開啟⌘O。檔案壞掉或不合法時，會告訴你哪裡有問題，不會開啟、也不會改動原檔。
    標題列的「已編輯」目前內容和上次存檔的內容不一樣。復原回到存檔時的狀態，「已編輯」就會消失。

    安全保護（Electron 版）

    • 安全寫檔：先寫暫存檔，確認寫入磁碟後才改名取代原檔，寫到一半斷電不會毀掉原檔。
    • 備份：每次存檔前，舊版會自動備份，每個檔案保留最近 20 版（可以在偏好設定改）。工具列「開啟備份…」可以依檔案瀏覽備份、預覽內容，選擇「開成新文件（副本）」或「取代目前文件內容」（可以用 ⌘Z 復原）。
    • 自動存檔與當機復原：有未存的變更時，每 30 秒（可以在偏好設定改）寫一份復原檔，不會覆蓋原檔。app 當機或被強制結束後，下次啟動會問你要不要恢復。
    • 關閉時：有未存的變更會問你儲存、不儲存或取消。選「不儲存」會刪掉復原檔，下次不會又出現。
    在瀏覽器裡跑（npm run dev）時功能比較少：「存檔」是下載一個新檔案（不會覆蓋上一次的）、沒有自動存檔和備份。要日常使用請用 Electron 版。

    偏好設定與關係表

    「偏好設定…」（⌘,）是 app 的設定，不會存進文件，也不影響已經存在的文件。

    • 檢視縮放、自動存檔間隔（10–600 秒）、備份保留版數（5–100）。
    • 新文件的預設版面：之後新增的文件會用這份版面（方向、邊界、字級、縮排、版面縮放等）。
    • 關係表（全域預設）：「關係表…」可以新增、修改、刪除、排序關係，設定次要句標記、主句標記、主句規則（有／無／可以指定）。
    全域關係表和文件裡的關係表是兩份。新文件建立時會複製一份全域表到檔案裡，所以之後你怎麼改全域表，舊檔案永遠顯示得和當初一樣。想讓目前的文件也用新增的關係，在關係表編輯器按「儲存並加入目前文件」，它只加入文件裡沒有的關係，不會改動已有的。

    常見問題

    我要怎麼建立括號？它說要選取兩個以上的項目，但我不知道怎麼選。

    點頁面最左邊灰色的行號選取行，按住 ⇧ 再點另一個行號可以選一段，然後按「建立括號」或 ⌘G。在文字裡拖曳選取的是文字，不是項目。詳見「選取行與括號」。

    已經建了括號，要在它上面再包一層括號？

    點那個括號的垂直線選取它，按住 ⌘ 再點要一起包的行號（或另一個括號的垂直線），然後 ⌘G。見「括號」那一節的兩個範例。

    選了關係之後，找不到可以確定、關閉面板的地方？

    面板上每個按鈕按下去就已經生效，所以沒有確定鈕。按面板右上角的「完成」或 Esc 關閉。做錯了用 ⌘Z。

    先打了中文，現在想加入希臘原文對照？

    版面設定 → 新增對照欄 → 語言選「希臘文」、模式選「逐行」→ 套用。然後點那一欄的格子貼上希臘文，預覽選「逐格貼上」。想以希臘文為分析欄，再用「與分析欄交換」。見「對照欄」「交換分析欄與對照欄」。

    為什麼有些行行首多了灰色的小數字？

    那是隱藏的經節錨點，在你移動或刪除行之後自動補上，用來保持每段文字所屬的經節不變。不會列印。見「經節」。

    為什麼貼上到對照欄不會直接貼進去？

    為了不誤蓋掉已有的內容，貼到對照欄一律先顯示預覽，讓你確認對應到哪一格、哪些格子已有內容。

    我選了「新增」選單裡的範例，我打的文件不見了？

    「新增…」選單是用範本開一份新文件，取代畫面上的文件。有未存的變更時會先問你，選「儲存」就會存檔。找回的方法：用「開啟」選你存的檔案，或（Electron 版）用「開啟備份…」。

    版面過窄的提示是什麼意思？

    分析欄的寬度（扣掉最深的縮排後）少於 40mm，文字會被擠得很窄。通常是對照欄太多或太寬、或縮排很深。提示列上有幾個一鍵的解法。

    縮放有兩種，差在哪裡？

    「版面縮放」在版面設定裡，會改變列印出來的大小；「檢視縮放」在工具列右邊，只改變螢幕上看起來的大小。

    括號左邊的黃色 ?、紅色 ! 會印出來嗎？

    不會。它們只是畫面上的提醒；匯出或列印前，如果還有這些項目，會顯示清單提醒你。

    括號被我刪掉行之後突然消失了或變了？

    這是自動整理：括號被搬空就刪掉；只剩一個子項就解除，剩下的子項接手它的位置並繼承標記。可以用 ⌘Z 復原。狀態列也會告訴你移除了幾個括號關係。

    我已經有一份文件了，能不能事後把和合本或英文加到對照欄？

    可以：工具列「加入經文對照…」，依文件裡的經節標記逐節放進對照欄，分析欄不會被動到。見「把內建經文加到既有文件的對照欄」。

    可以自動帶入聖經經文嗎？

    可以：工具列「新增…」→「從聖經帶入經文…」，選書卷和章節範圍，會建立新文件，和合本在分析欄、BSB 在對照欄。見「帶入經文」。

    想把中文和希臘文／英文對照，經文要自己打嗎？

    中文（和合本）、英文（BSB）、希臘文（SBLGNT，只有新約）都可以用「帶入經文」自動產生。NA28 這類有版權的版本需要你自己貼上。

    想把一行移到別的位置？

    最直接的是拖曳行號；也可以用 ⌥↑ ⌥↓，或「併入括號」「移出括號」。見「拖曳移動」。

    能不能一次選好幾個括號，或一次移動好幾行？

    可以：用 ⌘＋點或 ⇧＋點加選，再按對應的按鈕或直接拖曳。

    切換「逐行」和「整節」，原本的內容會不見嗎？

    不會。兩種模式的內容各自保留，切回去還在。

    想在文字裡的某一段加粗體，但跨了好幾行？

    每一格是獨立的編輯器，不能跨行選取文字。請一行一行分別設定。

    疑難排解

    打不出字

    字型載入完成後，游標會自動在第一行。如果沒有游標，點一下任何一行的文字，或點頁面空白處（會跳到最近的一行）。如果只有注音打不出字，請把右下角偵錯面板裡的記錄告訴開發者（面板可以用工具列「顯示偵錯面板」打開）。

    按「開啟」選了檔案，什麼都沒發生

    最新版本會顯示「已開啟檔案」，或在檔案有問題時跳出說明。如果還是沒有反應，請確認選的是 .verse 檔案；瀏覽器版的存檔是下載到「下載」資料夾。

    「建立括號」按了沒反應

    看畫面最底下的狀態列，會寫原因：沒有選取項目、項目不相鄰、不在同一個括號下，或包住了父括號的全部子項。

    頁面左邊被擠出螢幕

    視窗太窄、右側面板又開著時，頁面可以橫向捲動。按面板的「完成」關掉面板，或把視窗拉寬。

    匯出被擋下

    清單裡有 ⛔ 的項目必須先修正（整節對照區塊太高、字型未載入）。點清單項目會跳到位置。

    字型看起來不對

    每一欄依自己的語言選字型：希臘文和英文用內附的 Gentium Plus，繁體中文用宋體。檢查「版面設定」裡該欄的語言是否正確。

    已知限制

    • 一份文件只有一個分析欄；括號樹和縮排只套在分析欄。
    • 不能用滑鼠跨行選取文字。
    • 對照欄最多兩個，不能放經節標記。
    • 整節對照欄中，「文件裡已經沒有的經節」的譯文還留在檔案裡，但畫面上看不到。
    • 整節對照的區塊不能跨頁。
    • 內建經文只能加到對照欄，或用來建立新文件；不能把內建經文放進既有文件的分析欄。
    • 內建經文只有和合本（上帝版用字，可換成「神」）、BSB 和 SBLGNT（希臘文新約）；沒有舊約的希臘文或希伯來文原文，也沒有 NA28／UBS 等有版權的版本。
    • 希伯來文（從右到左）還沒支援。
    • 瀏覽器版沒有備份和自動存檔。
